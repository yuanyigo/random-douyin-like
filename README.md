# random-douyin-like · 随机播放抖音点赞过的视频

把你抖音「喜欢」列表里的视频做成一个可以随机回看的小工具。
不下载视频、不逆向签名、不碰 cookie。

---

## 准备

装 [Node.js](https://nodejs.org/)（18 以上）。别的都不用装。

## 第一步：采集点赞列表

打开网页版抖音「我的主页 → 喜欢」，然后二选一：

- **方式 A（不装东西）**：在喜欢页按 `F12` 打开 Console，粘贴同一个文件的全文。
  若提示不让粘贴，先手动输入 `allow pasting` 或 `允许粘贴` 回车，再粘。

- **方式 B**：装 [Tampermonkey](https://www.tampermonkey.net/) → 新建脚本 →
  粘贴 [`collector/douyin-likes-collector.user.js`](collector/douyin-likes-collector.user.js) 全文 → 保存。
  刷新喜欢页，右下角出现面板。


点面板里的「**开始采集**」，让它自己往下滚，滚到底会停（几千条大约几分钟）。
**采集期间别切走标签页** —— 后台标签会被浏览器限速到每分钟一次。

采完点「**下载 TXT**」。这份 TXT 是唯一可靠的备份，务必存好。

## 第二步：播放

双击仓库根目录的 **`start.bat`**，浏览器会自动打开 <http://127.0.0.1:5178>。

把刚才那份 TXT 的内容粘到左边「导入 ID」框里，点「**导入并打乱**」，就开始随机播了。

| 快捷键 | 作用 |
|---|---|
| `↑` `↓` | 上一个 / 下一个（鼠标滚轮在画面上滚也行）|
| `空格` | 播放 / 暂停 |
| `R` | 随机跳一个 |
| `O` | 在抖音里打开当前这条 |
| `F` | 全屏 |

队列会自动记住，下次打开这个网址直接从上次的位置继续。

## 停止

关掉 `start.bat` 开的那个黑窗口就行。
窗口找不到了就双击 **`stop.bat`**。

## 又点赞了新的怎么办

1. 重新走一遍第一步（面板会记住上次采的结果，新的直接并进去），重新下载 TXT。
2. 在播放页粘贴，这次点「**增量更新（保留已看进度）**」。

第 2 步别点「导入并打乱」—— 那个按钮会把整个队列换掉，已看记录一起清空，
之前看过的那几千条会被重新播一遍。「增量更新」只把新 ID 追加到末尾，顺序和进度都不动。

## 常见问题

**面板没显示「已载入上次采集的 N 个」**
采集结果存在浏览器的 `localStorage` 里，按「浏览器 + 用户配置 + 站点」隔离，
换浏览器、无痕窗口、清过站点数据都会让它变空。点面板里的「**从 TXT / JSON 恢复**」，
选之前下载的那份 TXT，就能读回来，不用重新采。

**用 Console 方式（方式 B）时，面板每次都要重新粘代码才出现**
正常现象，面板是代码，数据在 localStorage，两者互不影响。
